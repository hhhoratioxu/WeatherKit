## 原生记录和缓冲证据

以 UI 开始前记录的数据库最大 ID 为边界，只读关联脚本的 requestId 与会话 sessionId，并同时核对 requestStartTime。共关联到 6 条来自 com.apple.weather 的 WK3 JSON 请求：CN 3 条、GB 3 条，均为 HTTP 200 / application/json，脚本均完成，无脚本异常。记录中的 requestedCount 均为 0，不能用该字段推算实际供应商请求数量。

另外一条预警详情入口命中既有 html.request 脚本且脚本完成；其会话状态为 0，没有可确认的 App 进程归属或成功正文，因此不计为详情成功，也不将 0 当成 HTTP 错误码。

仅在本机受限权限忽略目录保存了 8 份脱敏真实缓冲 JSON。它们包含中国原始 HJ6332012.2604、修改后 EU.EAQI，以及英国 DAQI.2604；修改后的中国样本中当前天气及分钟降雨 metadata 为彩云天气，CO 数值分别为 1100 和 700 µg/m³，其中一份保留 1 条预警。英国样本保留 8 项污染物和 ppb 单位。缓冲本身不能单独证明 App 最终采用，因此将其与上述实际画面分别记录；不把不同缓冲直接宣称为同一 HTTP 会话的成对抓包。

此前的真实原生 AQ 图例探针 HK.AQHI 和 CN.AQHI.2604 均返回 HTTP 200，正文与现有 AirQualityScale.Build 输出逐字节一致，脚本完成且无异常。这不包含香港城市的完整天气验收。

本窗口 VPN 状态采样 380 次，覆盖约 419 秒，全部为 Connected；采样现已停止。这只是离散观测，不是无间隙或长期稳定性结论。没有重启应用或 VPN，也未改节点、路由、MITM、其他插件和系统网络设置。
