# v3.3.5

### 🆕 New Features
  * 新增 Surge 原生模块，与 Loon 同步支持新版 WeatherKit、空气质量算法、天气预警及详情。
  * Surge 增加请求合并、短时缓存、失败冷却和可选运行统计，支持独立模块参数。
  * Surge 的请求协商、功能列表与空气质量标尺采用独立轻量脚本。

### 🛠️ Bug Fixes
  * 修复 iOS 27.3 / macOS 27.3 天气预警编号格式不兼容，导致预警被忽略或不显示的问题。
  * 修复 Surge 只匹配旧版天气接口，升级后插件功能不生效的问题。
  * 修复 Surge 预警详情中 ids 位于首个查询参数时无法匹配的问题。
  * 修复 Surge 请求超时单位换算及跨请求缓存未启用的问题。
  * 将 CO 单位修正、六项污染物保留、指数目标控制和失败回退同步到 Surge。
