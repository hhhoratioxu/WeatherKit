#  iRingo: 🌤 WeatherKit

本 Fork 的 `main` 以 NSRingo 的原版 `v4.0.0-beta4`（`aab9c78`）为基准。沿用 WK3 原生 FlatBuffer 和被动 JSON 处理，并减少响应脚本不需要的 JSON 序列化。[上游 beta4](https://github.com/NSRingo/WeatherKit/releases/tag/v4.0.0-beta4)

Fork 测试版包含 Loon、Surge、Quantumult X、Stash 和 Egern 的导入文件。[v4.0.0-beta4-fork.1 附件与量测结果](https://github.com/hhhoratioxu/WeatherKit/releases/tag/v4.0.0-beta4-fork.1)
